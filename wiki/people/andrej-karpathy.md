## Overview

Andrej Karpathy wrote the LLM Wiki idea file on 2026-04-04 and published it as a gist meant to be pasted into a coding agent. The file describes a pattern. It leaves directory layout, page format, and tooling to whoever instantiates it.

## Working style

He keeps an agent session beside Obsidian, lets the model edit the wiki from the conversation, and browses the result live: links, graph, updated pages. He would rather ingest one source at a time and steer what the summary emphasizes than batch sources unattended. He treats that preference as personal. The schema of a given vault should record the variant actually in use.

The examples he gives for the pattern are personal tracking, research, reading a book, team knowledge from Slack and transcripts, and anything else that accumulates: competitive analysis, due diligence, trip planning, course notes, hobbies.
